Pinte o Ceará teste

Escolha um desenho e pinte cada quadradinho com a cor do número. No fim, uma história do lugar.

  • Toque numa cor embaixo; os quadradinhos dela ficam marcados.
  • Toque ou arraste o dedo para pintar. Só pinta onde a cor é certa.
  • Dois dedos aproximam e movem o desenho (ou use 🔍).
  • O que você pintou fica guardado só neste aparelho.
