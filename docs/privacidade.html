Política de privacidade

App Metrô Ceará (Android) e versão lite (no navegador) · atualizada em 23/10/2026

Resumo: o app não coleta, não guarda em servidor e não compartilha nenhum dado pessoal. Não tem cadastro, anúncios nem rastreadores. A sua localização é usada só dentro do celular.

Quem faz o app

O Metrô Ceará é um app não oficial, gratuito e de código aberto, feito por um passageiro, sem vínculo com o Metrofor, o Governo do Ceará ou a Prefeitura de Fortaleza. Todo o código pode ser conferido no GitHub.

Localização

  • É usada para mostrar a estação mais perto de você e, no modo viagem do app de Android, para acompanhar a viagem e avisar antes da sua estação, inclusive com a tela desligada, enquanto a viagem estiver ativa.
  • A posição é calculada e usada somente no seu celular. Ela não é enviada para ninguém, nem para o desenvolvedor, nem para terceiros.
  • O app não usa a localização em segundo plano fora do modo viagem. O modo viagem mostra uma notificação fixa enquanto está ligado e termina sozinho ao chegar ao destino.
  • Você pode negar a permissão: o app continua mostrando os horários, só não acha a estação mais perto sozinho.

Internet

O app usa a internet apenas para baixar os horários do dia, publicados pelo próprio Metrofor, de uma cópia hospedada no GitHub (raw.githubusercontent.com); a versão lite também é hospedada no GitHub Pages. Como em qualquer acesso a um site, o servidor do GitHub recebe dados técnicos da conexão (como o endereço IP), conforme a política de privacidade do GitHub. O desenvolvedor não tem acesso a esses dados e nada que identifique você é enviado pelo app.

O que fica guardado no celular

  • Os horários baixados, para funcionar sem internet.
  • As suas configurações (tema, distâncias e tempos do modo viagem, estação fixada).
  • O registro de testes, que só existe para o desenvolvimento: fica escondido, vem desligado e, se ligado, grava no próprio aparelho; só sai dele se você mesmo salvar o arquivo ou escolher uma pasta (por exemplo, no seu Google Drive) para o app guardar uma cópia lá.

Tudo isso some ao desinstalar o app ou apagar os dados dele (na versão lite, ao limpar os dados do site no navegador).

Outras permissões do app de Android

  • Notificações: para o aviso de descida e o acompanhamento da viagem.
  • Serviço em primeiro plano (localização): para o modo viagem continuar funcionando com a tela desligada.
  • Vibração: para o aviso de descida.

O lembrete na agenda abre o app de agenda do seu celular com o evento já preenchido; quem salva é você, e o Metrô Ceará não lê a sua agenda.

Crianças

O app não é direcionado a crianças e, como não coleta dados de ninguém, também não coleta dados de crianças.

Mudanças nesta política

Se o app passar a tratar algum dado de outro jeito, esta página será atualizada antes, com a nova data no topo.
